Before installing

Enable Developer Mode, confirm root SSH access, back up the tablet, and keep it charged. The safe path requires an already healthy Xovi/AppLoad installation. This is unsupported third-party software; firmware updates can invalidate stock-UI patches.

Safe installer — existing AppLoad

Recommended when AppLoad already opens normally. The computer downloads over validated HTTPS, verifies the published package hash, confirms AppLoad on the tablet, backs up the previous Estafette app, and switches directories atomically. On firmware other than the tested build, it installs the portable AppLoad tile and skips the stock-sidebar shortcut. 

curl -fsSLO https://sneakyottersec.github.io/Estafette/remarkable/install-safe.sh
less install-safe.sh
sh ./install-safe.sh root@10.11.99.1

Advanced installer — exact 3.28 runtime

This path refuses every device except reMarkable Paper Pro / Ferrari on OS 3.28.0.172. It installs checksum-pinned Xovi v19-23052026 and AppLoad v0.5.3, creates the firmware resource hashtable, applies the reviewed 3.28 compatibility patch, and returns to stock if xochitl fails its health check. It does not alter notebooks or embed passwords. 

curl -fsSLO https://sneakyottersec.github.io/Estafette/remarkable/install-advanced.sh
less install-advanced.sh
sh ./install-advanced.sh root@10.11.99.1

Optional triple-tap activation is explicit: add --triple-tap. It uses upstream revision 869497aa61435448bf0077fbf75fb264dcba92c5 and verifies installer SHA-256 c84f0c441118078a74bf3a7e1ee9aa136ab1fed3cc43668637a97a3cd0cddfa2. Estafette never installs automatic xochitl/systemd boot injection.

Manual package verification and install

Download the manifest and package on the computer, compare SHA-256, then copy only the AppLoad bundle:

curl -fsSLO https://sneakyottersec.github.io/Estafette/remarkable/app/v1/manifest.json
# Download package_url from manifest.json, then compare:
sha256sum estafette-rmpp-*.zip
unzip estafette-rmpp-*.zip
ssh root@10.11.99.1 'rm -rf /home/root/xovi/exthome/appload/.estafette-new; mkdir /home/root/xovi/exthome/appload/.estafette-new'
scp -r estafette/. root@10.11.99.1:/home/root/xovi/exthome/appload/.estafette-new/
ssh root@10.11.99.1 'set -eu; cd /home/root/xovi/exthome/appload; rm -rf estafette.previous; if [ -e estafette ]; then mv estafette estafette.previous; fi; mv .estafette-new estafette'

App cache lives separately at /home/root/.local/share/estafette/, so replacing the application does not erase downloaded reading content or QML reading state.
